Welcome! This castle is the demo site of Nano Server C, a web server written in fewer than 600 lines of C. It only knows a small part of HTTP, and this site shows each part on its own page. Every page, picture and stylesheet you see here was sent by that server, one request at a time.

★ News ★ The server no longer crashes when a visitor leaves in the middle of a download ★ Ctrl+C now closes the server cleanly, and you can start it again right away ★ DELETE is now recognized ★ The Server header is fixed ★

The Chambers

Each chamber shows one HTTP feature that the server implements. Every chamber has a button that sends a real request to the server and shows you the real response.

Six chambers, one feature each
ChamberWhat it shows
1. Request lineHow the server reads the method and the path, and finds the file to send.
2. MethodsThe HTTP methods the server recognizes, and why it answers all of them the same way.
3. Status codesThe status line, and the two codes the server sends: 200 OK and 404 Not Found.
4. HeadersThe headers sent with every response, including Connection: close.
5. Content typesHow the file extension decides the Content-Type.
6. StreamingA 2 MB picture sent in 4 KB pieces, announced by Content-Length.

Under Construction

These parts of HTTP are not implemented yet:

  • Keep-alive: every connection is closed after one response.
  • Query strings: ?page=2 becomes part of the file name.
  • Request headers and bodies, and HEAD responses without a body.
  • A default page for /: you have to ask for /index.html.
  • Chunked transfer encoding, compression and HTTPS.
  • A guestbook: the server can read files, but never write them.
