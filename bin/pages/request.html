Chamber 1The Request Line

Every request starts with one line, the request line. It holds three things: the method, the path and the HTTP version. The server reads this line and ignores the rest of the request.

Your browser asked for this page with this line:

GET /pages/request.html HTTP/1.1

How the Server Reads It

GET /pages/request.html HTTP/1.1
\_/ \_________________/ \______/
 |           |             |
 |           |             +-- version: read, then ignored
 |           +-- path: drop the first /, open the rest
 +-- method: written to the log
  • The method is the word before the first space. The server writes it to its log. See Chamber 2.
  • The path goes up to the next space. The server removes the first / and opens the rest as a file, relative to the folder where the server was started. /pages/request.html becomes pages/request.html.
  • The version is read, then ignored. The response always starts with HTTP/1.1.

What the Server Ignores

  • Everything after the first line: headers such as Host and User-Agent, and the body.
  • Query strings: /index.html?v=1 asks for a file named index.html?v=1, which doesn't exist. Try it above.
  • Percent-encoding: %20 isn't turned back into a space.

In the code src/http_request.c: read_request() reads the request, and parse_method() and parse_path() split the first line.
