Chamber 3Status Codes

The first line of every response is the status line: the HTTP version, a three-digit status code and a short reason. It tells the client whether the request worked. This server only sends two status codes.

Try It

Waiting

Choose a file to request.

You can also open the missing file directly, and your browser will show the JSON error.

Codes That Are Never Sent

The HttpStatus list in the code defines five more codes, but the server never sends them:

CodeReasonWhen a complete server would send it
201CreatedAfter a PUT or POST created something.
400Bad RequestWhen the request line doesn't make sense.
401UnauthorizedWhen a password is required.
403ForbiddenWhen the path points somewhere it shouldn't, like ../../etc/passwd.
500Internal Server ErrorWhen the server itself fails.

For 401 and 403, get_status_phrase() doesn't even have a reason yet: it would return Unknown.

In the code src/file_handler.c: send_file() chooses 200 or 404. The reasons come from get_status_phrase() in src/http_response.c.
